# Governance

This document outlines the governance model for the Agent Runtime Platform.

## Maintainers

The project is actively maintained by the core security team. Maintainers have merge access to the repository and are responsible for guiding the architectural direction of the IAM and Security engines.

- **Primary Contacts**: security@agent-runtime.com

## Decision Process

Major architectural changes (such as introducing new authentication paradigms or modifying the Policy Engine's conflict resolution strategy) require an RFC (Request for Comments). 

1. An RFC is submitted as a GitHub Issue labeled `rfc`.
2. Maintainers and community members discuss the proposal for a minimum of 7 days.
3. A consensus is reached by the Core Maintainers.

## Community Rules

We strictly adhere to our [Code of Conduct](CODE_OF_CONDUCT.md). We expect all contributors to maintain professional discourse, especially when discussing sensitive security vulnerabilities.
