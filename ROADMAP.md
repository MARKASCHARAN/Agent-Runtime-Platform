# Roadmap

Our roadmap is focused on cementing the platform as the definitive standard for enterprise Agent Identity and Access Management (IAM).

## Phase 1: Identity & Authorization (v1.0) - *Current*
- [x] Just-In-Time (JIT) Ephemeral Credentials
- [x] Zero-Trust Runtime Policy Engine
- [x] Human-in-the-Loop Approvals
- [x] Audit Logging (Execution Events)
- [x] Next.js SOC Dashboard MVP

## Phase 2: Active Defense (v2.0)
- [x] Prompt Injection Heuristics
- [x] Memory Entropy & Mutation Anomaly Detection
- [x] Data Loss Prevention (PII Context Filtering)
- [x] MCP Trust Hash Registry
- [ ] Automated Global Kill-Switch heuristics
- [ ] Integration with Datadog & Splunk SIEMs

## Phase 3: Swarm Observability (v3.0)
- [x] Distributed Tracing (`parentTraceId` linking)
- [x] Telemetry Payload Compression
- [ ] Chrome DevTools-style Agent Debugger UI
- [ ] Visual Agent Hive-Mapping (DAGs)

## Phase 4: Enterprise Integrations (v4.0)
- [ ] Native AWS IAM / Vault integration for secret dispensation
- [ ] Turnkey Okta OIDC support for dashboard admins
- [ ] Automated SOC2 Compliance Exporting
